# Jasonni — Photography

A responsive photography portfolio by Jasonni, built with semantic HTML, CSS, and vanilla JavaScript. All four displayed photographs are the owner's originals.

## Preview

Open `index.html` directly, or serve this folder with any static file server. For example, from this folder:

```powershell
py -m http.server 8000
```

Then visit `http://localhost:8000`.

## Project photographs

The Queensland landscape image is shown in its own award project. Three separate photographs are shown in the UQGCAA 2026 Calendar Project. Both galleries retain the original photographs' proportions; click an image to open the viewer, navigate with the arrows, or click the image to zoom. No location captions or generated image edits are added.

The award uses the confirmed event name, `2026 Queensland Multicultural Photography & Story Awards`, and describes the photographer as a landscape-category award recipient without stating an award tier. The supplied creative note describes sunrise at Mount Coot-tha Lookout, with trees and skyline framing two people beneath the same sky. The UQGCAA project title follows the name supplied by the photographer.

## Files

- `index.html` — semantic page and two project entries.
- `styles.css` — responsive monochrome editorial layout and accessible lightbox styling.
- `script.js` — image discovery for the documented filenames, gallery navigation, and click-to-zoom.
- `images/queensland-competition/award-landscape.jpg` — competition landscape photograph.
- `images/uqgcaa-calendar/photo-01.jpg` to `photo-03.jpg` — calendar project photographs.
